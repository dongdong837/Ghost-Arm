# 幽灵球尾臂：第一阶段机械结构

本阶段完成 Gazebo 实体结构、关节位置控制、实际关节反馈，以及底部 RGB-D 相机。现已增加 DH/逆运动学、球体间隙筛选与物理抓取；目标识别驱动的抓取尚未接入。当前逐句解释见 [总讲解](Ghost_Arm代码逐句讲解.md)。

## 结构

前方为 +X，左方为 +Y，上方为 +Z。尾臂安装在 -X 侧。

- 球体底部：24×18 cm 安装平面，下方偏前安装朝下的深度相机。
- 尾根 `tail_yaw`：绕 Z 轴旋转，限位 ±1.3 rad。
- 肩部 `tail_shoulder`：绕 Y 轴旋转，限位 [-1.6, 0.7] rad。
- 上臂：22 cm；肘部 `tail_elbow` 绕 Y 轴旋转，限位 ±1.8 rad。
- 前臂：20 cm；腕部 `tail_wrist` 绕 Y 轴旋转，限位 ±2.2 rad。
- 两指：沿相反 Y 方向平移，每指行程 3 cm。指长 8.5 cm，开口范围约 2–8 cm；后续应选择宽于最小开口的目标物。
- `grasp_center`：两指中间的抓取参考坐标系。

连杆具有质量、惯量、碰撞几何，四个旋转关节与两个滑动关节均由 Gazebo 位置控制器驱动。ROS 的 `/joint_states` 来自 Gazebo 实测状态，而不是命令角度。

`src/ghost_sim/simulation/tail_structure.py` 集中定义结构，`create_scene.py` 同步生成 SDF 和用于 RViz 的 URDF；修改尺寸后运行 `./ghost.sh build-model` 并重启仿真。

## 查看和动作

```bash
cd /home/ubuntu/ghost_arm
./ghost.sh start gui:=true
```

另开终端：

```bash
cd /home/ubuntu/ghost_arm
./ghost.sh arm hang    # 后方自然下垂并张开夹爪
./ghost.sh arm ready   # 向前伸到球体下方，夹爪朝下
./ghost.sh arm close   # 保持 ready 姿态并闭合夹爪
```

每条命令采用 4 秒平滑插值，并检查实际关节误差。`close` 是空载结构演示，不代表已完成抓取；这三个姿态也不是自动避碰路径。

## 相机和坐标

- `/grasp_camera/image`：底部彩色图。
- `/grasp_camera/depth_image`：底部深度图。
- `/grasp_camera/camera_info`：相机内参。
- `grasp_camera_optical_frame`：光学坐标，Z 朝下、X 朝图像右侧、Y 朝图像下侧。
- 原 `/camera/*` 前视相机仍保留。

## 当前范围

世界仍沿用零重力与理想悬浮控制；木块单独受到重量。现在已加入接触摩擦抓取、实际抬升判断、运动连杆自碰撞和球体间隙路径筛选，尚无完整的环境绕障规划。已有三维导航地图只考虑原球体尺寸，不能当作带尾臂的完整避障系统使用；当前建议在初始悬停位置演示尾臂。

## 本机验证

早期结构验证记录：SDF 格式校验通过，当时 17 项离线测试通过。当前 41 项测试和 -60° 抓取结果见总讲解。Gazebo 中已验证 hang → ready → close 的实际关节反馈，底部 320×240 深度图有有效测距。启动器分别启动仿真服务端和图形客户端，并配置虚拟机兼容的 Qt 渲染方式。

## 在 Gazebo 内手动控制尾臂与夹爪

启动 `./ghost.sh start gui:=true`，右侧 **Tail and gripper control** 面板已锁定 `ghost` 模型。

| 关节名 | 功能 | 单位 |
| --- | --- | --- |
| tail_yaw | 尾根左右转向 | rad |
| tail_shoulder | 肩部俯仰 | rad |
| tail_elbow | 肘部弯曲 | rad |
| tail_wrist | 腕部俯仰 | rad |
| finger_left_slide | 左指向外张开距离 | m |
| finger_right_slide | 右指向外张开距离 | m |

可拖动各关节滑块或输入目标数值。左右夹指各设为 0 表示最小开口，各设为 0.025 表示张开；对称开合时把两个数值设成相同。四个旋转关节的 ready 示例依次为 0、-0.663709、-0.671395、1.335104。先调整肩、肘，再调整腕，避免大幅跳变。Reset 会将所有关节目标设为零，不是恢复前伸姿态。

面板直接发送 Gazebo 标准关节命令话题；ROS 桥将原 `/ghost/arm/.../cmd_pos` 接口映射到相同控制器，因此终端命令仍然有效。执行终端姿态插值期间不要同时拖动面板，避免两个命令互相覆盖。GUI 手动目标不会经过 Python 的整段路径筛选，物理自碰撞约束不能代替规划；自动 IK 与抓取入口已具备球体间隙筛选。
