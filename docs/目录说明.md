## 命令替换

| 原命令 | 当前命令（在项目根目录执行） |
| --- | --- |
| ./start_sim.sh | ./ghost.sh start |
| ./view_ghost.sh | ./ghost.sh view |
| ./teleop.sh | ./ghost.sh teleop |
| ./navigate.sh X Y Z | ./ghost.sh goto X Y Z |
| ./ghost_ai.sh '任务' | ./ghost.sh ai '任务' |
| ./cancel_navigation.sh | ./ghost.sh stop |
| python3 create_scene.py | ./ghost.sh build-model |
| python3 voxel_map.py --query X Y Z | ./ghost.sh map --query X Y Z |
| 离线单元测试 | ./ghost.sh test |
| 实际飞行测试 | ./ghost.sh check-flight |
| 实际导航测试 | ./ghost.sh check-navigation |
| 源码打包 | ./ghost.sh package |

也可以从任何目录用绝对路径 `/实际路径/ghost-arm/ghost.sh start`。没有保留根目录旧脚本副本，避免再次散落一堆入口。

## 路径如何解析

scripts/env.sh 通过自己的位置定位项目根目录，加载 ROS，设置域 43 与 Gazebo 分区，将项目 src 加入 PYTHONPATH。

src/ghost_sim/paths.py 从自身路径向上两层定位根目录，统一提供 WORLD、MODEL、TEMPLATE、CONFIG、SCRIPTS、REPORTS、MAPS。运行输出目录按需创建，所以下载干净仓库时不需要先造 sensor_samples。

launch 文件使用 `python3 -m ghost_sim.模块.文件` 启动节点；跨模块导入同样用包名。生成器、控制器、导航、AI、测试均通过统一路径访问资产与输出文件。

## 文档阅读顺序

先看根目录 README 和本页，再看《代码逐句讲解》。讲解第 1～17 章中的源码行号和根目录路径是当时版本的历史快照；功能算法不变，当前文件位置与新增入口以本页和第 18 章为准。

## 压缩包内容

scripts/package.sh 只打包明确列出的源码、资产、配置、启动器、测试和文档，并排除缓存与常见密钥文件。runtime、dist、.git、截图和本地环境配置不进入压缩包。压缩包是源码分发包，不包含 ROS/Gazebo 系统依赖，也不是离线虚拟机镜像。
